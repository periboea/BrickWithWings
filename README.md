# BrickWithWings

## What this thing is.

custom flight controller built around the STM32F446RETx microcontroller that currently has no wings and lives entirely rentfree in my head.

no specific target UAV in mind. primary purpose as a learning ground.

## Current status.

what exists: schematic of the power supply, microcontroller core, and ICM-42688-P motion sensor wired up with 0 ERC errors.

what will exist in the future (probably. hopefully): proper layout of components' footprints. routing. more features.
